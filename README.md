# อุบัติเหตุบนทางหลวงช่วงสงกรานต์และปีใหม่
### Road accidents on Thai national highways during the "7 dangerous days"

วิเคราะห์ข้อมูลเปิดภาครัฐจาก [data.go.th](https://data.go.th) เพื่อตอบคำถามว่า **ช่วงเทศกาลอันตรายกว่าวันปกติแค่ไหน, เกิดเหตุที่ไหน ช่วงเวลาไหน เพราะอะไร** แล้วแปลงคำตอบเป็นข้อเสนอแนะเชิงนโยบายที่นำไปใช้ได้

> **สถานะ:** pipeline, test และ notebook เสร็จแล้ว ส่วน `reports/REPORT.md` และกราฟใน `reports/figures/` จะถูกสร้างเมื่อรันกับไฟล์ข้อมูลจริง (ดู [วิธีรัน](#วิธีรัน))

---

## ทำไมเลือกชุดข้อมูลนี้

ชุดข้อมูล **อุบัติเหตุบนทางหลวงแผ่นดิน (กรมทางหลวง)** เป็นข้อมูล *รายครั้ง* (หนึ่งแถว = อุบัติเหตุหนึ่งครั้ง) ซึ่งต่างจากชุดข้อมูลสรุปสถิติช่วงเทศกาลส่วนใหญ่บน data.go.th ที่รวมยอดมาแล้วหรือเป็น PDF ทำให้:

| ต้องการโชว์ | ชุดข้อมูลนี้ให้อะไร |
|---|---|
| ทำความสะอาดข้อมูลจริง | ไฟล์แยกรายปี หัวคอลัมน์ไม่ตรงกัน, ปี พ.ศ., เลขไทย, เวลาแบบ "14.30 น.", ชื่อจังหวัดหลายแบบ, พิกัดสลับกัน, แถวซ้ำ |
| วิเคราะห์ตามเวลา | มีวันที่ + เวลาเกิดเหตุ → เทียบเทศกาล/วันปกติ, วันที่เท่าไรของเทศกาล, ชั่วโมง, วันในสัปดาห์ |
| วิเคราะห์ตามพื้นที่ | มีจังหวัด + ละติจูด/ลองจิจูด → อันดับจังหวัด, ภาค, แผนที่จุดเกิดเหตุ |
| สาเหตุ | มีมูลเหตุสันนิษฐาน + ประเภทรถ → สาเหตุใดเพิ่มขึ้นช่วงเทศกาล |
| ข้อเสนอแนะนโยบาย | ตัดช่วง "7 วันอันตราย" ได้เองให้ตรงกับแคมเปญของรัฐ |

ตัวเลือกที่พิจารณาแล้วไม่เลือก: PM2.5 (ข้อมูลรายชั่วโมงหลักของกรมควบคุมมลพิษเผยแพร่ผ่าน air4thai เป็นหลัก ทำให้เรื่อง "ข้อมูลเปิดจาก data.go.th" ไม่ชัดเท่า), สถิติสงกรานต์รายจังหวัด (เป็นตัวเลขรวมหรือ PDF วิเคราะห์ตามชั่วโมง/สาเหตุไม่ได้)

## คำถามที่ตอบ

1. **เทียบวันปกติ** ช่วงปีใหม่และสงกรานต์มีอุบัติเหตุและผู้เสียชีวิต *ต่อวัน* มากกว่ากี่เท่า?
2. **วันไหนของเทศกาล** อันตรายที่สุด (วันเดินทางออก หรือวันเดินทางกลับ)?
3. **ชั่วโมงไหน** เกิดเหตุมากที่สุด และชั่วโมงไหนที่เกิดแล้ว *ตาย* มากที่สุด?
4. **จังหวัดไหน** มีผู้เสียชีวิตมาก (burden) และจังหวัดไหนที่เทศกาลทำให้ความเสี่ยงพุ่ง (lift)?
5. **สาเหตุ/ประเภทรถไหน** มีสัดส่วนเพิ่มขึ้นช่วงเทศกาล?

## วิธีการ

```
data/raw/*.csv|xlsx ─► clean.py ─► features.py ─► analysis.py ─► charts.py ─► reports/REPORT.md
  (ไฟล์รายปี)        ทำความสะอาด    ติดป้ายเทศกาล    aggregate      กราฟ PNG     insight + ข้อเสนอแนะ
                     + cleaning log                                         (คำนวณจากข้อมูลทั้งหมด)
```

**ช่วงเทศกาล** ใช้นิยามเดียวกับแคมเปญ "7 วันอันตราย" ของรัฐ: ปีใหม่ 29 ธ.ค.–4 ม.ค., สงกรานต์ 11–17 เม.ย.

**การทำความสะอาด** (`roadsafety/clean.py`, ทุกกฎมี test ใน `tests/test_clean.py`)

| ปัญหาที่เจอ | วิธีแก้ |
|---|---|
| หัวคอลัมน์ต่างกันในแต่ละปี (ไทย/อังกฤษ, เว้นวรรค, BOM) | ตาราง alias → ชื่อมาตรฐาน; ถ้าไม่เจอคอลัมน์ที่จำเป็นจะ error พร้อมบอกหัวคอลัมน์ที่มี |
| encoding (UTF-8 / TIS-620) | ลอง `utf-8-sig` → `cp874` → `tis-620` |
| วันที่ปน: `13/04/2566`, `13 เม.ย. 2566`, `๑๓/๐๔/๒๕๖๖`, `2023-04-13`, Excel serial | แปลงเลขไทย, ชื่อเดือนไทย, ปี พ.ศ. → ค.ศ., parse ISO และ d/m/Y แยกกัน (กัน pandas สลับวัน/เดือน) |
| เวลา: `14:30`, `14.30 น.`, `0230`, `25:99` | regex + ตรวจช่วง; ค่าที่ไม่ถูกต้องเป็นค่าว่าง (ไม่ทิ้งทั้งแถว) |
| จังหวัด: `จ.เชียงใหม่`, `กทม`, `โคราช`, `Chon Buri`, `ลําปาง` (สระอำพิมพ์ผิด) | ตารางอ้างอิง 77 จังหวัด (ไทย/อังกฤษ/ภาค) + alias |
| ละติจูด/ลองจิจูดสลับ, พิกัด 0,0 | สลับกลับถ้าเข้ากรอบประเทศไทย, นอกกรอบ → ว่าง |
| จำนวนผู้บาดเจ็บแยกสาหัส/เล็กน้อย, ช่องว่าง | รวมเป็น injuries, ช่องว่าง = 0 |
| มูลเหตุสันนิษฐานเป็นข้อความอิสระหลายร้อยแบบ | จัดกลุ่มด้วย keyword (ขับเร็ว, เมาแล้วขับ, หลับใน, ตัดหน้า ...) เก็บข้อความดิบไว้คู่กัน |
| แถวซ้ำภายในไฟล์และข้ามไฟล์ | dedupe ด้วย `ACC_CODE` |

**การวิเคราะห์ที่ระวังเป็นพิเศษ**
- อัตราต่อวันหารด้วย *จำนวนวันในปฏิทิน* ไม่ใช่จำนวนวันที่มีเหตุในไฟล์ (ไม่งั้นอัตราวันปกติจะสูงเกินจริง)
- เทียบรายวันของเทศกาลเฉพาะปีที่ข้อมูลครบทั้ง 7 วัน
- จังหวัด: แยก **burden** (ยอดรวม ใช้จัดสรรงบประจำ) กับ **lift** (เทศกาล ÷ วันปกติของจังหวัดเดียวกัน ไม่ต้องใช้ข้อมูลประชากรหรือความยาวถนน) และไม่คำนวณ lift ถ้ามีเหตุช่วงเทศกาลน้อยกว่า 20 ครั้ง

## วิธีรัน

```bash
pip install -r requirements.txt

# 1) หา dataset id แล้วดาวน์โหลดไฟล์ CSV/XLSX ทุกปีลง data/raw/
python -m roadsafety.download --search "อุบัติเหตุ ทางหลวง"
python -m roadsafety.download --dataset <dataset-id>
#    (หรือดาวน์โหลดจากหน้าเว็บ data.go.th เองแล้ววางไฟล์ไว้ใน data/raw/)

# 2) ทำความสะอาด + วิเคราะห์ + สร้างรายงาน
python -m roadsafety.report

# 3) test
pytest
```

ผลลัพธ์:
- `reports/REPORT.md` — key findings, กราฟ 10 รูป, ตาราง, ข้อเสนอแนะเชิงนโยบาย, cleaning log, ข้อจำกัด
- `reports/cleaning_log.csv` — จำนวนแถวที่ถูกแก้ในแต่ละขั้น แยกรายไฟล์
- `data/processed/accidents_clean.csv` — ข้อมูลที่สะอาดแล้ว (เปิดใน Excel ได้, UTF-8 BOM)
- `notebooks/walkthrough.ipynb` — เดินผ่านทุกขั้นแบบ interactive

## โครงสร้างโปรเจกต์


## ข้อจำกัด

- เป็นข้อมูลบนโครงข่ายของกรมทางหลวงเท่านั้น ไม่รวมทางหลวงชนบท ถนนท้องถิ่น และทางพิเศษ จึงไม่ใช่ยอดรวมทั้งประเทศ
- ผู้เสียชีวิตนับ ณ ที่เกิดเหตุ/เวลารายงาน ต่ำกว่าตัวเลขเสียชีวิตภายใน 30 วันตามนิยาม WHO
- มูลเหตุสันนิษฐานเป็นการประเมินของเจ้าหน้าที่ และการจัดกลุ่มใช้ keyword จึงควรมองเป็นตัวชี้วัดเชิงแนวโน้ม
