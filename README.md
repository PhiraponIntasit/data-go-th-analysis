# อุบัติเหตุทางถนนช่วงสงกรานต์และปีใหม่: "7 วันอันตราย" อันตรายกว่าจริงแค่ไหน?
### Road accidents during Songkran and New Year on Thailand's national road network

วิเคราะห์ข้อมูลเปิดภาครัฐ **อุบัติเหตุบนโครงข่ายถนนของกระทรวงคมนาคม** ซึ่งเป็นข้อมูลรายครั้ง 168,300 ครั้ง ช่วง ม.ค. 2562 – ต.ค. 2569 เพื่อตอบคำถามว่าช่วงเทศกาลอันตรายกว่าวันปกติแค่ไหน, เกิดเหตุที่ไหน ช่วงเวลาไหน เพราะอะไร แล้วแปลงคำตอบเป็นข้อเสนอแนะเชิงนโยบาย

📊 **Interactive dashboard: [phiraponintasit.github.io/data-go-th-analysis](https://phiraponintasit.github.io/data-go-th-analysis/)** กรองตามช่วงเทศกาล ปี ภาค จังหวัด แล้วทุกกราฟเปลี่ยนตาม

📄 **รายงานฉบับเต็ม: [`reports/REPORT.md`](reports/REPORT.md)** (กราฟ 10 รูป, ตาราง, cleaning log, ข้อจำกัด)

## สิ่งที่พบ (Key insights)

1. **ตัวเลข "เทศกาลอุบัติเหตุเพิ่ม 4 เท่า" ส่วนหนึ่งเกิดจากวิธีเก็บข้อมูล**
   - จำนวนอุบัติเหตุที่บันทึกกระโดดจากวันละ ~53 เป็น ~200–230 ครั้ง ในวันแรกของแคมเปญ "7 วันอันตราย" พอดี แล้วตกกลับในวันหลังแคมเปญจบ ถนนจริงไม่มีทางมีรถเพิ่ม 4 เท่าข้ามคืน
   - สัดส่วนรายงานจากกรมทางหลวงชนบทเพิ่มจาก 4% เป็น 14% ของทั้งหมด
   - "เมาแล้วขับ" เพิ่มจาก 0.8% เป็น 6.4% ของสาเหตุ ซึ่งชี้ว่าแบบฟอร์มและความเข้มข้นในการรายงานช่วงแคมเปญต่างจากปกติ
   - **ดังนั้นห้ามเอาอัตราช่วงเทศกาลหารวันปกติแล้วสรุปว่าเสี่ยงกว่ากี่เท่า**
2. **ต่ออุบัติเหตุหนึ่งครั้ง เทศกาลไม่ได้ตายง่ายกว่า:** ผู้เสียชีวิตต่ออุบัติเหตุ 100 ครั้ง ปีใหม่ 13.0, สงกรานต์ 13.5, วันปกติ 13.3
3. **วันที่อันตรายที่สุดคือวันหยุดหลัก:** 1 ม.ค. (เฉลี่ย 41.6 ศพ/วัน) และ 12 เม.ย. (34.1 ศพ/วัน) ส่วนวันท้ายๆ ของแคมเปญเบาลงชัดเจน
4. **ผู้เสียชีวิตต่อวันแคมเปญมีแนวโน้มลดลง:** ปีใหม่ลดลง 29% (37.5 → 26.5 ศพ/วัน) และสงกรานต์ลดลง 21% (ปีแรกๆ ได้รับผลจากโควิด จึงต้องอ่านอย่างระวัง)
5. **ช่วงเย็นเกิดบ่อย แต่กลางคืนตายง่าย:** ช่วงแคมเปญ 18% ของอุบัติเหตุเกิดเวลา 16:00–19:00 แต่อุบัติเหตุเวลา 22:00–04:00 มีผู้เสียชีวิต 19.9 ต่อ 100 ครั้ง เทียบกับ 9.9 ในเวลากลางวัน
6. **รถจักรยานยนต์:** คิดเป็น 38% ของอุบัติเหตุช่วงแคมเปญ และมีผู้เสียชีวิต 33.4 ต่อ 100 ครั้ง สูงกว่ารถเก๋ง 3.8 เท่า
7. **5 จังหวัดคิดเป็น 16% ของผู้เสียชีวิตช่วงแคมเปญ:** นครราชสีมา เชียงใหม่ อุดรธานี สุราษฎร์ธานี เชียงราย ส่วนจังหวัดที่เกิดเหตุแล้วตายง่ายที่สุดคือ อุบลราชธานี ระยอง นครปฐม นครพนม สระแก้ว

## ข้อเสนอแนะเชิงนโยบาย

1. **วัดผลแคมเปญให้ถูกวิธี:** อย่าใช้ตัวเลข "7 วันอันตราย ÷ วันปกติ" เป็นหัวข่าว ให้ติดตาม *ผู้เสียชีวิตต่อวันแคมเปญเทียบปีต่อปี* และ *ผู้เสียชีวิตต่ออุบัติเหตุ 100 ครั้ง* แทน และเก็บข้อมูลวันปกติให้ครบเท่าช่วงแคมเปญ
2. **ย้ายด่านตรวจแอลกอฮอล์ไปช่วงกลางคืน (22:00–04:00)** ซึ่งเป็นช่วงที่เกิดเหตุแล้วตายง่ายที่สุด ส่วนช่วง 16:00–19:00 เน้นจัดการจราจร
3. **ทุ่มทรัพยากรในวันพีค (31 ธ.ค.–1 ม.ค. และ 12–13 เม.ย.)** แทนการกระจายเท่ากันทั้ง 7 วัน
4. **เน้นผู้ขับขี่จักรยานยนต์:** บังคับใช้กฎหมายหมวกกันน็อก และทำแคมเปญเดินทางกลับอย่างปลอดภัย
5. **แยกจังหวัดเป็นสองกลุ่ม:**
   - กลุ่มที่มีผู้เสียชีวิตรวมสูง ต้องการด่านตรวจและรถพยาบาลเพิ่ม
   - กลุ่มที่เกิดเหตุแล้วตายง่าย ต้องทบทวนการออกแบบจุดเสี่ยงและเวลาเข้าถึงการรักษา
6. **เผยแพร่ข้อมูลในรูปแบบเดียวกันทุกปี:** ใช้วันที่แบบ ISO และรหัสอุบัติเหตุที่คงที่ (ดูปัญหาที่เจอด้านล่าง)

## การวิเคราะห์ที่ระวังเป็นพิเศษ

- **ตรวจช่วงแคมเปญจากข้อมูล** ไม่ใช้วันที่ตายตัว เพราะวันเริ่มแคมเปญเลื่อนไปทุกปี (สงกรานต์ 2564 เริ่ม 9 เม.ย., ปีใหม่ 2568 เริ่ม 27 ธ.ค., สงกรานต์ 2563 ถูกยกเลิก)
  - วันในฤดูเทศกาลที่มีอุบัติเหตุ ≥ 1.8 เท่าของค่ามัธยฐาน 29 วัน และต่อเนื่องกัน ≥ 4 วัน ถือเป็นวันแคมเปญ
  - หลักฐานรูปขั้นบันไดดูจากวันที่ตายตัว (29 ธ.ค./11 เม.ย.) แยกต่างหาก จะได้ไม่วนกลับมาพิสูจน์ตัวเอง
- **อัตราต่อวันหารด้วยจำนวนวันในปฏิทิน** ไม่ใช่จำนวนวันที่มีเหตุในไฟล์
- **ใช้ตัวชี้วัดที่ไม่ขึ้นกับปริมาณการรายงาน** (ผู้เสียชีวิตต่ออุบัติเหตุ 100 ครั้ง, การเทียบภายในช่วงแคมเปญ, การเทียบปีต่อปี) แทนการเทียบเทศกาลกับวันปกติตรงๆ
- ตัดแคมเปญที่ไม่ครบเพราะอยู่ตรงขอบช่วงข้อมูล (ปีใหม่ 2562) ออกจากการเทียบรายวันและรายปี

## วิธีรัน

```bash
pip install -r requirements.txt

python -m roadsafety.download      # ดาวน์โหลด CSV 8 ไฟล์ (~86 MB) ลง data/raw/
python -m roadsafety.report        # ทำความสะอาด + วิเคราะห์ + เขียน reports/REPORT.md (~20 วินาที)
python -m roadsafety.dashboard     # สร้าง docs/index.html (dashboard ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย)
pytest                             # 49 tests
```

- `notebooks/walkthrough.ipynb`: เดินผ่านทุกขั้นแบบ interactive (สำรวจข้อมูลดิบ → cleaning → วิเคราะห์)
- `data/processed/accidents_clean.csv`: ข้อมูลที่ทำความสะอาดแล้ว เปิดใน Excel ได้ (ไม่ได้ commit ไว้ใน repo รันแล้วจะได้เอง)

## ข้อจำกัด

- ครอบคลุมเฉพาะถนนของกระทรวงคมนาคม ไม่รวมถนนท้องถิ่น/เทศบาล ซึ่งเป็นที่เกิดอุบัติเหตุจักรยานยนต์จำนวนมาก จึงไม่ใช่ยอดรวมทั้งประเทศ
- ผู้เสียชีวิตนับ ณ ที่เกิดเหตุ/ตอนรายงาน ต่ำกว่าตัวเลขเสียชีวิตภายใน 30 วันตามนิยาม WHO
- ความครบถ้วนของการบันทึกช่วงแคมเปญกับวันปกติต่างกัน อัตราส่วนระหว่างสองช่วงจึงเป็นค่าสูงสุด (upper bound) ไม่ใช่ค่าจริง
- มูลเหตุสันนิษฐานเป็นดุลยพินิจของเจ้าหน้าที่ และการจัดกลุ่มใช้ keyword จึงควรมองเป็นตัวชี้วัดเชิงแนวโน้ม
- แถวที่วันกับเดือนสลับแต่ไม่มีหลักฐานให้จับได้ (ไม่มีวันรายงานหรือรหัสซ้ำมาช่วยยืนยัน) ยังอาจหลงเหลืออยู่
